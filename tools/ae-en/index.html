5Export

Only these two files go to After Effects.

  • revealmap.png — the reveal map itself. A still the same size as your composition, where darker means painted earlier.
  • stride11_fade_params.json — stride, plane order, duration and the threshold formulas. Handy as a record; the script does not require it.

6Wiring it up in After Effects

The idea

The map luminance v (0–254) is the order in which a cell gets painted. With the progress of plane p defined as


  
that plane's mask is simply the region where v < 255 × progp. So ramping a threshold from 0 to 255 reproduces the sweep. The three planes reuse the same map, each delayed by one third.


  
After Effects (bundled script)

  
Run stride11_fade.jsx with a composition open, pick the base and overlay layers, and it builds this:

  
[master comp]
  Stride11 Fade CTRL (null) — Slider Control "Fade Progress" 0-100  <- animate this one
  Stride11 Fade OUT (solid) — Set Channels
      red   <- MIX_1 red
      green <- MIX_2 green
      blue  <- MIX_0 blue
      alpha <- base layer alpha
  MIX_0 / MIX_1 / MIX_2   video off (only referenced by Set Channels)

[MIX_p]  top to bottom
  MASK_p    revealmap.png + Threshold
  OVERLAY   luma INVERTED track matte from MASK_p
  BASE      the base image

  
A luma track matte multiplies with the layer's own alpha, so transparent parts of the overlay keep showing the base. Threshold paints v ≥ L white, and the side we want is v < L, which is why the matte is inverted.


  
Choosing "all three at once" removes the plane split entirely, leaving one mask and one track matte. That is the lightest setup — though you lose the blue-to-magenta-to-full-colour staging.
