リビールマップ生成

フェード全体を 静止画1枚 に畳み込みます。各セルが「いつ塗られるか」を明度で持つ画像を書き出し、AE 側はしきい値を1本のキーフレームで動かすだけ。連番マスクは要りません。

5書き出し

AE に渡すのはこの2つだけです。

  • revealmap.png — リビールマップ本体。暗いほど早く塗られるセルを表す、コンポジションと同じ大きさの静止画。
  • stride11_fade_params.json — ストライド・プレーン順・尺・しきい値の式。スクリプトが読みます。

6After Effects での組み方

共通のしくみ

リビールマップの明度 v（0〜255）は「そのセルが塗られる順番」です。プレーン p の進行度を


  
とすると、そのプレーンのマスクは v < 255 × progp の領域。つまりしきい値を 0 → 255 へ直線的に動かすだけで掃引が再現されます。3プレーンは同じマップを 1/3 ずつ遅らせて使います。


  
After Effects（同梱スクリプト）

  
stride11_fade.jsx をコンポジションで実行し、元レイヤーと重ね合わせレイヤーを選ぶと、下記の構造を自動で組みます。

  
[マスターコンポ]
  CTRL (調整レイヤー) ─ Set Channels
      Source1 = MIX_R から 赤
      Source2 = MIX_G から 緑
      Source3 = MIX_B から 青
      Source4 = 元レイヤー から アルファ
  Fade Progress スライダー（0〜100）… これ1本をアニメートする

[MIX_B] ┐  上から: MASK_B（マップ＋しきい値）
[MIX_R] ├─          重ね合わせレイヤー（TrkMat = MASK のルミナンス反転）
[MIX_G] ┘           元レイヤー


  
ルミナンス反転トラックマットは重ね合わせレイヤー自身のアルファと掛け算されるので、透明部分はそのまま元画像が残ります。しきい値は v ≥ L を白にするので、出したい v < L 側を取るために反転を使っています。


  
「3プレーン同時」を選ぶとプレーン分けが無くなり、マスク1枚＋ルミナンストラックマット1つだけで完成します。なお だけで完結させたい場合はこちらが現実的です（ただし青→紫→フルカラーの色の段取りは出ません）。
